## 🚀 Selected Projects

### 🌽 Integrated Multimodal Corn Crop Health Monitoring System
**AI · Computer Vision · Mobile · Research**

Multimodal crop-health platform integrating **leaf disease detection, pest identification, nutrient deficiency prediction, and yield prediction** into a Flutter mobile application. My contribution focused on the **ResNet50 nutrient-deficiency module**, which achieved **83% test accuracy** and included **Grad-CAM explainability**.

**Tech:** Python · TensorFlow/Keras · ResNet50 · Grad-CAM · TensorFlow Lite · FastAPI · Flutter

[![View Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Chathumadura/A-MULTIMODAL-SYSTEM-FOR-AUTOMATED-CORN-DISEASE-DETECTION-AND-FARMER-CENTRIC-KNOWLEDGE-SHARING-New)

### 🖥️ Asset Management System — Sri Lanka Tea Board
**Enterprise Desktop Application**

Desktop-based system for managing organizational IT assets including **desktops, laptops, scanners, UPS units, printers, and photocopiers**, with CRUD operations, repair-history tracking, MySQL integration, and PDF reporting.

**Tech:** Electron · JavaScript · HTML/CSS · MySQL · jsPDF

[![View Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Chathumadura/Asset-Management-System)

**Tech:** Flutter · FastAPI · SQLite
